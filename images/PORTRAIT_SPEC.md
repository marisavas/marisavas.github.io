# Portrait Image — Specification

Status: placeholder in use (`portrait-placeholder.svg`). Replace with final photo when available.

## Recommended master file

- **Aspect ratio:** 4:5 (portrait)
- **Minimum size:** 1200 × 1500px
- **Preferred delivery:** 2400 × 3000px (allows downscaling/retina without quality loss)
- **Format:** JPEG or WebP, sRGB
- **Crop:** head-and-shoulders, centered, plain/neutral background consistent with the Editorial Scientific direction (canonical_decisions.md §16–18) — no busy backgrounds, no other people, no logos/branding visible

## Usage

The 4:5 master can be cropped down to 1:1 (square) if a given layout (e.g. a compact author byline) needs it — deriving a square crop from a 4:5 original is straightforward; the reverse is not. Do not source a 1:1-only photo.

## Where it's used (per functional_specification.md)

- Home → Hero ("primary portrait")
- About → Portrait (top of page)

Both usages are implemented in later phases (Phase 3 Home, Phase 5 About) — this file only reserves the asset spec so those phases don't need to renegotiate cropping.
